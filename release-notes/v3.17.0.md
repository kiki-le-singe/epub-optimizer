## New: local graphical interface

Optimize one book from your browser without typing CLI options. The interface runs on your own machine and uses the same optimizer and EPUBCheck validation as the command line.

```bash
docker compose -f compose.ui.yaml up -d --build
```

Then open <http://127.0.0.1:8787>. From an installed package or source checkout with Java and EPUBCheck available, `pnpm ui` (or the `epub-optimizer-ui` command) starts the same server natively.

- Choose or drop one EPUB, pick **Balanced**, **Lossless images** or **Author workflow**, follow progress, cancel, and download the optimized book with its HTML/JSON reports.
- Strict validation is always on: the EPUB is downloadable only after content checks and EPUBCheck pass with no errors or warnings.
- French, English, Italian, Spanish and German; light, dark and system themes with green or blue accents. Choices are remembered by the browser.
- Built with React, Tailwind CSS and shadcn/ui components, bundled locally: no CDN, external fonts, analytics or account at runtime.

## Compatibility and operational limits

- Existing CLI commands, presets, reports and the Node.js API are unchanged. The interface is opt-in; the Docker image still starts the CLI by default and starts the interface only with `--ui`.
- The service listens on `127.0.0.1:8787` by default and is designed for a single local user. **Do not expose it to the Internet or LAN.** Requests require a per-session token, a same-origin check and a localhost `Host` header.
- One book at a time, up to 256 MiB, one active job per server, a 15-minute job timeout and image concurrency fixed at one. The Compose service is limited to two CPUs, 2 GiB of memory and 1 GiB of temporary storage; large expanded archives may exceed these limits below the upload limit.
- Uploaded copies and results are temporary and are removed at the next job or shutdown. The original file on your computer is not modified.
- Batch processing, watched folders, inspection/repair-only modes and advanced options remain CLI features. Interface messages are translated; engine diagnostics and downloaded reports keep their original language. Validation does not certify visual rendering on every reading system.
- Release automation can mirror the tested stable image index to Docker Hub when configured; prereleases are not mirrored. The README now documents npm and Docker Hub installation, an offline Docker quick start and preservation of host file ownership.
