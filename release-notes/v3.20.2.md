## Fixed: license comments are kept in minified scripts

The optimizer minifies the book's JavaScript files with Terser, which was configured to remove every comment. That included license notices such as `/*! lib v1.0 | MIT License */` or `/** @license … */`, which licenses like MIT require to be kept when the code is redistributed. Comments starting with `/*!` or containing `@license`, `@preserve`, `@copyright` or `@cc_on` are now kept; other comments are still removed. Stylesheets and inline `<script>` elements already kept them.

## Fixed: a script is no longer rewritten larger

Minification can make already compact code grow, for example `a=1` becoming `a=1;`. Such a script was rewritten anyway; it is now kept unchanged, as images and stylesheets already are when re-encoding offers no size benefit.

## Fixed: `--temp=` and `--lang=` values containing `=`

The standalone scripts cut these values at a second `=`: `--temp=/books/a=b` used `/books/a`. The whole value after the first `=` is now used.

## Tests

32 new tests cover code that had little or no coverage:

- archive extraction refuses parent and backslash traversal, absolute and drive paths, NUL bytes, symbolic links and the temporary directory marker, and enforces size limits on actual bytes even when an entry declares a smaller size;
- the content integrity check follows `srcset`, `poster`, CSS `@import`, NCX navigation and spine entries;
- minified scripts keep the global names that XHTML event handlers call.

CI coverage floors rise accordingly (statements 86 %, branches 78 %, functions 90 %, lines 88 %).

## Compatibility

- Output changes only for `.js` files that contain license comments (a few bytes larger) and for scripts that minification would have enlarged (now unchanged).
- No change to options, defaults, reports or the Node.js API.

## Validation

792 unit tests pass with 4 Linux-only skips on macOS. Feature PR and post-merge CI pass on Node 22/24, including installed-package checks and EPUBCheck E2E, and native Linux AMD64/ARM64 Docker tests pass. Each new archive safety test was checked by disabling the protection it covers: the test fails, then passes again with the protection restored.
