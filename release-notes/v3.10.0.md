## New feature

**Optional background for transparent PNGs:** use `--png-background '#RRGGBB'` to flatten eligible transparent PNGs onto an explicitly chosen opaque color before JPEG conversion. Conversion and resizing share one encoding pass. The option works for single-book and batch optimization; Node API callers can set `args.pngBackground`.

```bash
epub-optimizer -i book.epub -o book-white.epub --png-background '#ffffff'
```

## Compatibility and visual trade-offs

- **There is no default background.** Existing commands and presets keep their previous behavior when the option is omitted. Transparent PNGs remain PNG by default.
- Flattening permanently replaces transparency, including around image captions, with the chosen color. A white background can produce visible white rectangles in dark reading modes. JPEG is lossy: inspect image text, fine details and edges in the target readers. EPUBCheck and content/text checks do not certify visual quality.
- Only an opaque six-digit hex color (`#RRGGBB`) is accepted. Quote the value in the shell. Invalid colors, including colors with alpha, are rejected before processing.
- The option is rejected with the `lossless` preset, `--no-convert-png`, or doctor mode. Lossless optimization without this option continues to preserve raster image bytes.
- Existing conversion safeguards remain: PNGs smaller than 200 KiB and animated PNGs are skipped; JPEG candidates must be smaller than the source PNG and have a manifest entry with safely rewritable references. A candidate that cannot be committed keeps the original PNG.
- Candidate EPUBCheck validation still precedes output publication. Validation failure or timeout preserves an existing output EPUB. Node.js 22.12 or newer remains supported; packaged optimization still requires Java and EPUBCheck.

## Validation

Regression coverage includes transparent and semi-transparent pixels on white and custom backgrounds, safe reference updates, no-size-benefit and missing-manifest rollback, default alpha retention, lossless byte preservation, APNG preservation, batch propagation and preflight output protection. The local suite passes 535 tests with one existing skip; CI runs Node 22/24 and native Linux AMD64/ARM64 Docker tests and scans.
