## Security and release checks

- Make the production dependency audit part of **Required CI**. Failed, cancelled or skipped audits now block merges and automatic release preparation.
- Require a successful production audit before building release candidates or creating/resuming a draft, including retries that reuse an existing tested image record. Audit registry errors remain blocking, and the manual and weekly audits remain available.

## Docker runtime

- Refresh the digest-pinned Node 24 Bookworm runtime to Node.js 24.22.2, and update the pinned Debian Bookworm image used to install EPUBCheck. Both image indexes include native Linux AMD64 and ARM64 variants.
- Update the pinned Docker Buildx and build-push actions to 4.4.1 and 7.4.0. Runtime security packages are still refreshed on every build; promotion still uses the exact tested image digests without rebuilding them.

## Development and CI

- Update ESLint to 10.14.0, typescript-eslint to 8.72.1 and Vite to 8.3.5.
- Upgrade Vitest, its UI and its V8 coverage provider together to 5.1.0. Keep the existing tests and coverage thresholds; the covered set remains the same 43 source files.
- Migrate the pinned checkout, Node setup, pnpm setup and Java setup actions to their Node 24 implementations, including the shared project setup action. The project still uses pnpm 10.30.3, TypeScript 6.0.3, Node 22 types and Java 17 for EPUBCheck.
- Check that Git authentication remains available in the temporary linked worktrees used by release preparation and branch synchronization, without printing credentials or making an authenticated network request.

## Compatibility

- Minimum Node.js version remains 22.12.0. CLI options, defaults, presets and report formats are unchanged.
- Pull the 3.7.6 Docker image to receive the updated runtime. Previously published version images are not rewritten.
