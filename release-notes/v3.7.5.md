## Fixed

- Preserve the original XHTML document when HTML minification changes element nesting or order, identifiers, namespace declarations, or the position of character data. Unsafe minification is skipped and logged, including cases where a nested `<meta/>` would close a paragraph early while leaving its text unchanged.
- Discover XHTML by its OPF media type, including atypical filenames, and recognize uppercase `.XHTML` extensions and equivalent namespace or DOCTYPE quoting.

## Security updates

- Update Cheerio's Undici dependency from 7.29.1 to 7.30.1, addressing the eight production dependency advisories reported by the audit (four high and four moderate).
- Refresh Debian runtime packages for every new CI and release image build instead of reusing the cached system-update layer. This includes Debian's `libbrotli1` security update for CVE-2026-111497 in the newly tested runtime images.
- Keep dependency, compilation and EPUBCheck caches. Stable image tags still receive the exact tested digests without rebuilding during promotion.

## Release automation

- Wait for incomplete GitHub CI and release-catalogue state within bounded retry periods, with diagnostics identifying the source commit, run and observed status. Completed CI failures and API/authentication errors remain blocking.
- Use the same release App for develop CI verification and preparation, including dry runs. Recheck the develop commit before creating the release branch.
- Bind published-release events to the expected release ID, and continue to reject manually dispatched drafts before image promotion.

## Compatibility

- Minimum Node.js version remains 22.12.0; no CLI flags or defaults change.
- A skipped XHTML transformation leaves the original file byte for byte. Other resources can still be optimized, and final EPUBCheck validation remains required.
- Pull the 3.7.5 Docker image to receive the refreshed runtime packages; previously published version images are not rewritten.
