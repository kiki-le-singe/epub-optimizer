## Fixed

- Preserve inline CSS child selectors, quoted values, escaped style attributes and CDATA sections in XHTML. Unsupported or unsafe CSS is retained instead of being partially rewritten.
- Keep UTF-8 prose as text instead of expanding it into numeric character references, and preserve `>` inside quoted image attributes when adding lazy loading.
- Make strict EPUBCheck validation independent of the Java locale. Warnings fail validation through EPUBCheck's native exit status, warning totals remain visible in JSON reports, and strict mode rejects unreadable validation summaries.
- Resolve the bundled EPUBCheck JAR from the installed package, so the CLI also works when started from another directory. `EPUBCHECK_PATH` remains available for an explicit override.
- Preserve animated PNG (APNG) files byte-for-byte in both PNG conversion and image recompression. APNGs are left unchanged even when downscaling is requested. Chunk scanning is bounded on pathological PNG inputs.
- Compare animated WebP dimensions per frame. Keep the original bytes when recompression would increase size without actually shrinking frames; preserve frame timing and loop count when resizing.

## Release automation

- Prepare releases and synchronize branches through pull requests with successful CI on their exact head and base commits.
- Use the dedicated GitHub App restricted to this repository. Release automation follows branch protections without bypassing required checks.
- Promote the recorded, tested Docker digests after publication, without rebuilding the images.

## Compatibility

- Minimum Node.js version remains 22.12.0.
- APNG resizing is intentionally skipped to preserve animation.
- Strict mode may now reject books with warnings that previously slipped through under a non-English Java locale, or runs whose validation diagnostics are incomplete.
