## New: optional WebP conversion

`--convert-webp` converts PNG and JPEG images to WebP when the result is smaller. It is **off by default**: older reading systems, including some e-ink devices and conversion services, do not display WebP. Test the result on the readers you target and keep the original book.

```bash
epub-optimizer -i book.epub -o book-optimized.epub --convert-webp --strict --clean
```

- Lossy WebP at `--jpg-quality`, with transparency preserved, so transparent PNGs no longer need palette quantization or `--png-background`. `--max-image-dim` and JPEG EXIF orientation are applied in the same encode.
- The image quality guard applies. Below `--min-image-ssim`, a PNG falls back to lossless WebP and a JPEG to quality 92; if that is not smaller or still below the threshold, the original image is kept.
- References in XHTML, CSS, SVG and `srcset`, and the OPF manifest item, are rewritten as one transaction per image. An image without a rewritable reference keeps its original file.
- Kept in their original format: EPUB 2 packages (WebP is a core image type only since EPUB 3.3), the cover image, animated PNGs, images under 10 KB, and images whose `.webp` name is already taken.
- The option is refused with the lossless preset, which preserves image bytes.

## Compatibility

- Without `--convert-webp`, output is unchanged from 3.18.0.
- JSON reports list a "Convert images to WebP" step, skipped unless the option is set, and `imageQuality` records can carry the new operation `to-webp`.
- `Args` and JSON configuration accept the optional `convertWebp` / `"convert-webp"` setting.
- The SSIM measurement of the image quality guard now reads its candidate into memory. Results of the optimizer are unchanged; this removes a dependency on libvips file caching being disabled.
- A `type="image/png"` hint on a `<source>` element or in a CSS `image-set()` is not rewritten when its image is converted.

## Validation

742 unit tests pass with two existing skips. Feature PR and post-merge CI pass on Node 22/24, including installed-package checks and EPUBCheck E2E, which now runs a `--convert-webp --strict` conversion that EPUBCheck must accept. Native Linux AMD64/ARM64 Docker tests pass. New Linux-only tests cover the watch guard's refusal of hard-linked and symlinked guard files.

Measured in single local runs on one 60 MB Pages-exported book (12 transparent PNGs and 1 JPEG, `balanced --strict`, macOS ARM64, Node 24), which is not a general figure:

|                  | Output  | SSIM range     | EPUBCheck             |
| ---------------- | ------- | -------------- | --------------------- |
| default          | 8.69 MB | 0.895 to 0.959 | 0 errors / 0 warnings |
| `--convert-webp` | 1.96 MB | 0.911 to 0.972 | 0 errors / 0 warnings |
