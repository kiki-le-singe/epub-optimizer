## Content preservation

- Refuse EPUBs containing an internal DTD subset before parsing metadata, taking text snapshots or processing content. Custom entity declarations could otherwise change the book's text while both EPUBCheck and the text integrity check still passed.
- Scan file prologs without expanding entities or fetching external resources. Detect internal subsets in UTF-8 and UTF-16 documents, including files with nonstandard extensions, and report the affected file.
- Apply this guard to every preset, with or without `--strict`. On refusal, preserve the input and any existing output file. Regression tests cover all four modes and both strictness settings with a generated EPUB validated by EPUBCheck.

## Release automation

- Wait up to three minutes when a successful PR workflow's `Required CI` job metadata is still missing or pending. Keep the existing overall timeout and recheck the PR, target branch and exact CI run before merging.
- Continue to stop immediately on failed or duplicate gates, API errors and changed branches. This also protects branch synchronization after publication.
- Update the pinned GitHub Actions: pnpm setup 6.1.1, artifact upload 7.0.2, artifact download 8.0.2 and Docker login 4.7.0. Align pnpm setup in the shared project action with the audit workflow.

## Compatibility

- EPUBs with any internal DTD subset, including empty or comment-only subsets, are now rejected conservatively. Replace internal declarations with literal text or numeric character references before retrying. This release does not add a custom DTD entity resolver.
- Ordinary doctypes and standard EPUB 2 external DTD declarations remain supported.
- CLI options, default presets, production dependency versions, the pinned pnpm version and the Node.js 22.12 minimum are unchanged.
