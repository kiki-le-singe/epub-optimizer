## New features

- **Offline HTML reports:** `--report-html` shows archive size changes, processing diagnostics, EPUBCheck and output publication status, and resource changes before/after optimization. Reports are standalone and contain no external assets or scripts.
- **Batch optimization:** `--batch` and `--output-dir` process the EPUB files directly inside a directory, sequentially in filename order. Each book gets a JSON report; requesting an HTML summary also produces per-book HTML reports. A failed book is recorded and the remaining books continue.

```bash
epub-optimizer --batch books --output-dir optimized --preset balanced --clean \
  --report-json reports/batch.json --report-html reports/batch.html
```

Existing single-book commands keep their defaults. Batch mode is non-recursive; exit code 0 means all books succeeded, while exit code 1 indicates a book failure or a planning/report error. Existing output EPUBs remain protected when validation fails.
